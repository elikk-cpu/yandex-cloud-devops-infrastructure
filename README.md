# Yandex Cloud DevOps Infrastructure

Учебный DevOps-проект в Yandex Cloud.

Цель — развернуть отказоустойчивую инфраструктуру для статического сайта с мониторингом, логированием и резервным копированием.

## Stack

- Yandex Cloud
- Terraform
- Ansible
- Nginx
- Prometheus
- Grafana
- Elasticsearch
- Filebeat
- Kibana
